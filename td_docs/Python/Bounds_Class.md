# Bounds Class

A NamedTuple representing an axis-aligned bounding region, containing min, max, center, and size, each expressed as a [Position](Position_Class.md "Position Class").

See also [SOP Class](../SOPs/SOP_Class.md "SOP Class"), [POP Class](POP_Class.md "POP Class")

## Members

`min` → `Position` **(Read Only)** :

The bounds minimum position.

`max` → `Position` **(Read Only)** :

The bounds maximum position.

`center` → `Position` **(Read Only)** :

The bounds center position.

`size` → `Position` **(Read Only)** :

The bounds size as a position.

## Methods

No operator specific methods.
