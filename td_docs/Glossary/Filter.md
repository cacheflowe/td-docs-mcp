# Filter

Operators that need 1 or more inputs (to create a meaningful output) are called Filters in TouchDesigner, like a [Math CHOP](https://docs.derivative.ca/Math_CHOP "Math CHOP"). "Inputs" are both the wires from other operators, and references to other operators in OP parameters.

Filters are the lighter shaded operators in the [OP Create Dialog](https://docs.derivative.ca/OP_Create_Dialog "OP Create Dialog").

See their counterparts [Generators](https://docs.derivative.ca/Generator "Generator").

Operators may have inputs defined by [Parameters](https://docs.derivative.ca/Parameter "Parameter") that are [Path](https://docs.derivative.ca/Network_Path "Network Path") references to other operators, that are from any [Operator Family](https://docs.derivative.ca/Operator_Family "Operator Family").
