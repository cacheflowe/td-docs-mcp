# GLSL

GLSL is the OpenGL Shading Language, used in TouchDesigner to define 3D shaders in [Materials](https://docs.derivative.ca/MAT "MAT"), and 2D shaders in [GLSL TOPs](https://docs.derivative.ca/GLSL_TOP "GLSL TOP").

See also [Shader](https://docs.derivative.ca/Shader "Shader"), [Write a GLSL Material](https://docs.derivative.ca/Write_a_GLSL_Material "Write a GLSL Material"), [Write a GLSL TOP](https://docs.derivative.ca/Write_a_GLSL_TOP "Write a GLSL TOP"), [GLSL Multi TOP](https://docs.derivative.ca/GLSL_Multi_TOP "GLSL Multi TOP"), plus the [GLSL Category](https://docs.derivative.ca/Category:GLSL "Category:GLSL") and [Rendering Category](https://docs.derivative.ca/Category:Rendering "Category:Rendering").
