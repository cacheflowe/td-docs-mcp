# GLSL

GLSL is the OpenGL Shading Language, used in TouchDesigner to define 3D shaders in [Materials](../MATs/MAT.md "MAT"), and 2D shaders in [GLSL TOPs](../TOPs/GLSL_TOP.md "GLSL TOP").

See also [Shader](Shader.md "Shader"), [Write a GLSL Material](../Interoperability/Write_a_GLSL_Material.md "Write a GLSL Material"), [Write a GLSL TOP](https://docs.derivative.ca/Write_a_GLSL_TOP "Write a GLSL TOP"), [GLSL Multi TOP](../TOPs/GLSL_Multi_TOP.md "GLSL Multi TOP"), plus the [GLSL Category](https://docs.derivative.ca/Category:GLSL "Category:GLSL") and [Rendering Category](https://docs.derivative.ca/Category:Rendering "Category:Rendering").
