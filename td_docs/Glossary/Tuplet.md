# Tuplet

A tuplet is the set of [parameters](Parameter.md "Parameter") on one line of the parameter dialog.

For example, on a Transform SOP, a tuplet `t` contains the parameter `tx`, `ty` and `tz`.

A tuplet can contain one parameter. In this case, the tuplet name is the parameter name.

Tuplets occupy a [page](../Python/Page_Class.md "Page Class") of parameters.

See also: [Page_Class](../Python/Page_Class.md "Page Class")

A [Operator Family](Operator_Family.md "Operator Family") that reads, creates and modifies 3D points, polygons, lines, particles, surfaces, spheres and meatballs. Particles and point clouds are now done primarily on the GPU using TOPs.
