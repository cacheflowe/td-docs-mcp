# Tuplet
A tuplet is the set of [parameters](https://docs.derivative.ca/Parameter "Parameter") on one line of the parameter dialog.
For example, on a Transform SOP, a tuplet `t` contains the parameter `tx`, `ty` and `tz`.
A tuplet can contain one parameter. In this case, the tuplet name is the parameter name.
Tuplets occupy a [page](https://docs.derivative.ca/Page_Class "Page Class") of parameters.
See also: [Page_Class](https://docs.derivative.ca/Page_Class "Page Class")
A [Operator Family](https://docs.derivative.ca/Operator_Family "Operator Family") that reads, creates and modifies 3D points, polygons, lines, particles, surfaces, spheres and meatballs. Particles and point clouds are now done primarily on the GPU using TOPs.
