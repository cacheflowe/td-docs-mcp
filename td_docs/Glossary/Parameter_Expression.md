# Parameter Expression

A parameter expression is a Python expression that is in the expression field of a parameter. This can be a simple math equation or a complex expression using [Python](https://docs.derivative.ca/Python "Python"). Some common python expressions in parameters are in [Python Tips](https://docs.derivative.ca/Python_Tips "Python Tips").

For help with Python, refer to [Python](https://docs.derivative.ca/Category:Python "Category:Python").

**Tip** : Long expressions in parameters can be edited in your text editor by clicking in the expression and pressing Ctrl-e. You can also select Edit Expression in the parameter's right-click menu.

( Nodes can be put into the legacy expression format, [Tscript](https://docs.derivative.ca/Tscript "Tscript"). For a list of all Tscript expressions, refer to [Tscript Expressions](https://docs.derivative.ca/Tscript_Expressions "Tscript Expressions") or open the [textport](https://docs.derivative.ca/Textport "Textport"), put it in tscript mode by clicking the language option in the upper left, then type `exhelp`. )

A text string that contains data (string, float, list, boolean, etc.) and operators (+ * < etc) that are evaluated by the node's language (python or Tscript) and returns a string, float list or boolean, etc. Expressions are used in parameters, [DATs](https://docs.derivative.ca/DAT "DAT") and in scripts.

TouchDesigner's original built-in Command scripting language prior to [Python](https://docs.derivative.ca/Python "Python").
