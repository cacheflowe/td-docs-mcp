# Panel

A Panel, or Control Panel is a custom graphical user interface user control built within TouchDesigner. See [Panel Component](https://docs.derivative.ca/Panel_Component "Panel Component"), which are used to create such user interfaces.

The "look" of a panel is created using the [Text COMPs](https://docs.derivative.ca/Text_COMP "Text COMP") and [TOPs](https://docs.derivative.ca/TOP "TOP").

The "feel" or behavior is determined by the settings of the [Panel Components](https://docs.derivative.ca/Panel_Component "Panel Component"), the [Panel Execute DAT](https://docs.derivative.ca/Panel_Execute_DAT "Panel Execute DAT"), [Extensions](https://docs.derivative.ca/Extensions "Extensions") in the panel, the panel member of the [panelCOMP Class](https://docs.derivative.ca/PanelCOMP_Class "PanelCOMP Class"), and the use of the Panel CHOP which turns [Panel Values](https://docs.derivative.ca/Panel_Value "Panel Value") into CHOP Channels.

To display a panel in a floating or fixed-position window on your monitors, use the [Window COMP](https://docs.derivative.ca/Window_COMP "Window COMP").

While editing, a panel can be viewed by
  * right-clicking on a [Panel Component](https://docs.derivative.ca/Panel_Component "Panel Component") and selecting _View..._
  * changing [Pane](https://docs.derivative.ca/Pane "Pane") type to _Panel_
  * clicking on the [Pane Bar](https://docs.derivative.ca/Pane_Bar "Pane Bar") the square icon (Open Viewer) if you are working inside a Panel component
