# Expression

An Expression in TouchDesigner is a text string that contains data (string, float, list, boolean, etc.) and operators (+ * < etc) that are evaluated by the [operator's language](https://docs.derivative.ca/Operator_Language "Operator Language") (python or Tscript) and returns a string, float list or boolean, etc.

Expressions are used in [Parameters](Parameter.md "Parameter"), [DATs](DAT.md "DAT") (especially the [Evaluate DAT](../DATs/Evaluate_DAT.md "Evaluate DAT")), [Tscript Commands](https://docs.derivative.ca/Tscript_Commands "Tscript Commands") and [Scripts](Script.md "Script").

For Python expressions, see [Python](https://docs.derivative.ca/Category:Python "Category:Python").

There is a Python expression execution engine to improve the perforamnce of Python expressions, read about it here: [Optimized Python Expressions](https://docs.derivative.ca/Optimized_Python_Expressions "Optimized Python Expressions")

For Tscript expressions, see [Tscript Expressions](https://docs.derivative.ca/Tscript_Expressions "Tscript Expressions").
