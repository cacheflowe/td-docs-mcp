# Viewer Flag

The Viewer [Flag](https://docs.derivative.ca/Flag "Flag") is the top-left flag on every node. It toggles the individual node's [Node Viewer](https://docs.derivative.ca/Node_Viewer "Node Viewer") on and off.
[![Viewer Flag.jpg](https://docs.derivative.ca/images/d/db/Viewer_Flag.jpg)](https://docs.derivative.ca/File:Viewer_Flag.jpg)
See also [Flag](https://docs.derivative.ca/Flag "Flag").
