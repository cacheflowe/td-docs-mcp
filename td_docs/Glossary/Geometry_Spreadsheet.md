# Geometry Spreadsheet

The **Geometry Spreadsheet** was one of TouchDesigner's [Pane](https://docs.derivative.ca/Pane "Pane") Types. Change to Geometry Spreadsheet by using the Pane Type Menu or using the **Alt+7** shortcut.

Currently, use a [SOP to DAT](https://docs.derivative.ca/SOP_to_DAT "SOP to DAT") to look at SOP data values. It shows detailed information about Points or [Primitives](https://docs.derivative.ca/Primitive "Primitive") in a SOP.

Currently, use a [SOP to DAT](https://docs.derivative.ca/SOP_to_DAT "SOP to DAT") to look at SOP point/polygon XYZ and other attributes. Formerly a [Pane](https://docs.derivative.ca/Pane "Pane") type.

There are 8 pane types; Network, Panel, Textport, Geometry Viewer, TOP Viewer, CHOP Viewer, Parameters, Graph Editor for CHOP Channels, or a Geometry Spreadsheet.

A [Operator Family](https://docs.derivative.ca/Operator_Family "Operator Family") that reads, creates and modifies 3D points, polygons, lines, particles, surfaces, spheres and meatballs. Particles and point clouds are now done primarily on the GPU using TOPs.
