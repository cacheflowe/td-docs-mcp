# .toe

A **TouchDesigner Environment file** (`.toe`), or "Project file", is the file type used to save your TouchDesigner projects. It contains your [networks](Network.md "Network"), [operators](../General/Operator.md "Operator"), [parameters](https://docs.derivative.ca/index.php?title=Parameters&action=edit&redlink=1 "Parameters \(page does not exist\)"), [Pane](Pane.md "Pane") layouts and optionally [MIDI](../Interoperability/MIDI.md "MIDI") settings.

External to the `.toe` file are media files like images, movies, 3D geometry, audio and other data files. However, these media files can also be embedded into `.toe` files or `.tox` files.

A [.tox](.tox.md ".tox") (component) file is used to save particular [components](Component.md "Component") of a `.toe` so one file can be shared between projects, archived or simply transported to another project. The `.toe` files can refer to `.tox` files and load them in when you start TouchDesigner.

A `.toe` file can be converted to ASCII-readable form using `toeexpand[](https://docs.derivative.ca/Toeexpand "Toeexpand")`. After editing in ASCII form, the `.toe` file can be recreated using `toecollapse[](https://docs.derivative.ca/Toecollapse "Toecollapse")` to a format with TouchDesigner can use.

TOuch Environment file, the file type used by TouchDesigner to save your entire project.

TouchDesigner Component file, the file type used to save a [Component](Component.md "Component") of your TouchDesigner project.
