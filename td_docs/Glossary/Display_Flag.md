# Display Flag
Display [flags](https://docs.derivative.ca/Flag "Flag") (light blue) are found on [TOPs](https://docs.derivative.ca/TOP "TOP"), [CHOPs](https://docs.derivative.ca/CHOP "CHOP"), and [SOPs](https://docs.derivative.ca/SOP "SOP") and [Object](https://docs.derivative.ca/Object "Object") components.
##  Display Flag for Network Backdrop and Viewer Panes
Turning on an operator's Display flag will allow the OP's data to be viewed in a [Viewer](https://docs.derivative.ca/Viewer "Viewer") pane (ie [TOP Viewer](https://docs.derivative.ca/TOP_Viewer "TOP Viewer"), [SOP Viewer](https://docs.derivative.ca/SOP_Editor "SOP Editor"), [CHOP Viewer](https://docs.derivative.ca/CHOP_Viewer "CHOP Viewer"), or [Geometry Viewer](https://docs.derivative.ca/Geometry_Viewer "Geometry Viewer") respectively).
If a [Network Editor](https://docs.derivative.ca/Network_Editor "Network Editor") pane has the backdrop display option enabled, then the OPs of that type with their display flags on will be shown in the backdrop of the editing pane. The network will 'float' on top. Backdrop display is enabled using the network editor's right-click menu, **Display > Backdrop TOPs** (or Backdrop CHOPs/Backdrop Geometry).

See also [Render Flag](https://docs.derivative.ca/Render_Flag "Render Flag") and [Flag](https://docs.derivative.ca/Flag "Flag").
##  Display Flag for Geometry and Camera Viewers
The same Display flag on 3D components is used to select objects to view in a Camera component, and in the parent's viewer.
The blue [flag](https://docs.derivative.ca/Flag "Flag") on Geometry components and SOP operators determines if the geometry contained in that operator is visible in node viewers and geometry viewer panes. See [Render Flag](https://docs.derivative.ca/Render_Flag "Render Flag").
The Backdrop is the grid of node viewers that are visible behind the [Network](https://docs.derivative.ca/Network "Network"), set by turning on Display Flags and the network RMB -> Display... Backdrop OPs.
