# Designer Mode
In Designer Mode, you edit your [Network](https://docs.derivative.ca/Network "Network"), [Nodes](https://docs.derivative.ca/Node "Node") and [Parameters](https://docs.derivative.ca/Parameter "Parameter") in the [Network Editor](https://docs.derivative.ca/Network_Editor "Network Editor"), [Animation Editor](https://docs.derivative.ca/Animation_Editor "Animation Editor") and other [Panes](https://docs.derivative.ca/Pane "Pane").
In contrast, [Perform Mode](https://docs.derivative.ca/Perform_Mode "Perform Mode") is the user interface you create in Designer Mode.
Designer Mode has its [Application Shortcuts](https://docs.derivative.ca/Application_Shortcuts "Application Shortcuts"), distinct from those of Perform Mode.
See also [Perform Mode](https://docs.derivative.ca/Perform_Mode "Perform Mode"), [Window Placement](https://docs.derivative.ca/Window_Placement_Dialog "Window Placement Dialog"), [Privacy](https://docs.derivative.ca/Privacy "Privacy").
You edit your networks in Designer Mode. See [Perform Mode](https://docs.derivative.ca/Perform_Mode "Perform Mode").
Perform Mode is an optimized mode for live performance that only renders one specified [Window COMP](https://docs.derivative.ca/Window_COMP "Window COMP") which is one window that contains your video outputs and your (optional) control interface. In Perform Mode the network editing window is not open - you edit your networks in Designer Mode. Alternate with F1 and Esc.
