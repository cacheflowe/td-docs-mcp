# Designer Mode

In Designer Mode, you edit your [Network](Network.md "Network"), [Nodes](Node.md "Node") and [Parameters](Parameter.md "Parameter") in the [Network Editor](Network_Editor.md "Network Editor"), [Animation Editor](https://docs.derivative.ca/Animation_Editor "Animation Editor") and other [Panes](Pane.md "Pane").

In contrast, [Perform Mode](Perform_Mode.md "Perform Mode") is the user interface you create in Designer Mode.

Designer Mode has its [Application Shortcuts](Application_Shortcuts.md "Application Shortcuts"), distinct from those of Perform Mode.

See also [Perform Mode](Perform_Mode.md "Perform Mode"), [Window Placement](https://docs.derivative.ca/Window_Placement_Dialog "Window Placement Dialog"), [Privacy](Privacy.md "Privacy").

You edit your networks in Designer Mode. See [Perform Mode](Perform_Mode.md "Perform Mode").

Perform Mode is an optimized mode for live performance that only renders one specified [Window COMP](Window_COMP.md "Window COMP") which is one window that contains your video outputs and your (optional) control interface. In Perform Mode the network editing window is not open - you edit your networks in Designer Mode. Alternate with F1 and Esc.
